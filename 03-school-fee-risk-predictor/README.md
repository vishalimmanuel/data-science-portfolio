# School Fee Risk Predictor

A small data-science app that estimates how likely a family is to pay school fees late, so a school can send reminders to the right families early.

> **Important:** all data in this project is **synthetic**. It was generated by `train.py`, and no real student or family information is used. The model re-discovers the patterns I built into the generator, so the scores show that the workflow works, not that these patterns hold in a real school.

## What it does
1. Generates 1,200 synthetic students (grade band, fee, income band, siblings, distance, past late payments, reply habits, concession)
2. Explores late-payment rates by group
3. Trains and compares Logistic Regression and Random Forest with 5-fold cross-validation
4. Evaluates on a hidden test set (ROC-AUC, precision and recall, confusion matrix)
5. Serves predictions in a [Streamlit](https://streamlit.io) web app with a low, medium or high risk suggestion

## Results (synthetic data)
| Model | Cross-validation ROC-AUC |
|---|---|
| Logistic Regression | 0.924 |
| Random Forest | 0.898 |

Test set: ROC-AUC **0.903**, accuracy **82%**. Charts are in [`outputs/`](outputs).

## Run it
```bash
pip install -r requirements.txt
python train.py          # creates the data, trains, saves model.joblib
streamlit run app.py     # opens the web app
```

## Skills shown
Synthetic data generation, pandas, scikit-learn pipelines with preprocessing (one-hot encoding, scaling), classification metrics, model saving with joblib, Streamlit app
